# S008：分离式第二轮 Optuna（model search 冻结换手层）

更新时间：2026-10-10 00:19

## 协议

《下一步》第二十一节的定义：**第二轮 Optuna，把 model search 和 turnover search 分开**，不是把 50 trials 机械加到 200。动机是 S003 联合搜索的 fANOVA 显示 `band_keep_q` 占 75.30% 方差、`learning_rate` 只占 19.19%——模型参数从未被独立、干净地搜过。

- **Phase A（model search）**：`band_keep_q` 冻结在 T030 q\* = 0.0022778298112255263，不参与搜索；只搜 9 个模型参数（S003 搜索空间去掉 `band_keep_q`）。TPE 50 trials（同 S003 预算），目标 = wf2021/2022/2023 三折 band(q*) 官方综合分均值。trial 0 = T030 锚点，逐折 1e-9 断言复现冻结值。
- **confirm2024** 在搜索结束后对 winner 评一次（不参与搜索目标）；替换门槛 = confirm2024 band(q*) ≥ 0.3873823479（T030 冻结值）。
- **Phase B（turnover search）**：winner 原始预测上跑 keep_q 网格 {q\*, 0.005, 0.01, 0.02, 0.03, 0.05, 0.075, 0.10, 0.15, 0.20, 1.0}（只重编码 band，不重训），confirm2024 同网格对照。
- 特征集固定 V1 40 特征（复用 S003 缓存 `90fc43d7de70`，identity 逐位校验）；测试期不碰。

## 结论

1. **S008 不通过替换门槛，retain_S003（T030 冻结）**：confirm2024 = 0.3774348396 < 0.3873823479（−0.009948）；《下一步》成功标准「2023 → 0.38+」也未达成（0.3605，虽是三折搜索中 2023 折的最好成绩，但离 0.38 仍远）。
2. **分离搜索的方法论价值被证实，但量级有限**：模型参数这一个自由度的干净搜索把三折均值抬了 +0.0031，方向（400 轮 + lr≈0.05）与 S003 联合搜索时被 keep_q 方差淹没的判断吻合；但 confirm2024 上三折增益完全反转（−0.0099），**第 8 次「折上优势在确认折/测试期反转」**。
3. **超额项依旧是唯一瓶颈**：winner 在 2024 折 IC 只差 −0.0038、超额差 −0.0288——调参、换特征（S007）、换损失（S005/S006）三条线全部撞在同一堵墙上。Top 1/10 的实现超额至今没有被任何一条研究线抬动过。
4. **换手层结论稳固**：q\* 在分离搜索的 winner 上仍是最优 keep_q，冻结 q\* 的基线在换手维度已无改进空间。
