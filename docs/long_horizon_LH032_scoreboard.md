# LH032 评分总表：四折 + 测试期，全部竞争模型

口径：`final = 0.4·IC + 0.3·E + 0.3·(1−T)`，均用官方 `src/evaluation/official_eval.py` 的实现内部复算。
- **IC**：逐日全池 Spearman（只剔 y 缺失，不剔涨停）
- **E**：逐日剔涨停 + y 缺失，top `len//10` 等权 − 有效池均值，日均 × 252
- **T**：top 集合逐日 Jaccard 距离均值
- **α / profile**：E 的 DGTW 分解，`E = α + profile`；下标 vol / amt 表示按该因子十层分解。本文统一用 **vol60 分解的 α** 与 **log_amt 分解的 profile**（两者各自主导的那一轴）

四折区间：`wf2021` 20210104–20211231（243 日）、`wf2022` 20220104–20221230（242 日）、`wf2023` 20230103–20231229（242 日）、`confirm2024` 20240102–20241231（242 日）。
测试期：2025–2026，344 个交易日，标签为本地自建（`test_y_2025_2026/测试集_Y.csv`）。

### LH032 倾斜的原理（三条实证依据）

1. **profile 可外推**（推翻了「profile 不能外推」的前提）。
   `profile = Σ_b (w_b^B − w_b^V)·(m_b − mkt)` —— 暴露差你能控制、可外推，**层溢价才是那一半风险**。
   用过去半年估的层溢价去倾斜，看下一个未见半年窗口是否真拿到钱（11 个窗口，θ=1.0）：
   rev1 follow +0.1124（oracle 的 99.8%）、log_amt +0.0863（106%）、mom20 +0.0757（98.2%）、vol60 +0.0664（96.4%）、mom60 +0.0624（99.4%）；**reverse 全负、random ≈ 0、断档检验全不显著**（mwu_p 最低 0.29）。六个因子定义已逐一核对无前视。

2. **但必须两条轴**。`corr(层内 IC, 层溢价)` 在 5/6 个因子上四折稳定为负（mom60 −0.77~−0.98、vol60 −0.87~−0.99、rev1 −0.80~−0.99、mom20 −0.80~−0.98、log_amt −0.21~−0.94）。
   **判别力最强的层恰好是溢价最低的层** ⇒ 没有单因子能同时拿 α 和 profile。
   故：`log_amt φ<0`（往小成交额）专拿 profile，`vol60 φ>0`（往高波动）专拿 α，副作用互相抵消。

3. **杠杆在池内重排（stage2），不在候选池（stage1）**。
   只倾斜阶段1 候选池、池内仍按 H01：Δprofile 只有 stage2 的 1/5，Δα 照样掉，Δfinal 全负 ⇒ 已证伪。
