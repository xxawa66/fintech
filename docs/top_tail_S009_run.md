# S009 运行协议：冻结预测的头部与留仓诊断

依据 [S009–S011 计划第 4 节](top_tail_research_plan.md)，用户于 2026-10-10 要求完成 S009。

## 固定范围

- 19 个模型年度：T030 / Y4 / S007-market / S008-T033 各四年，Y1 三年；raw 与原 q* band 共 38 单元。
- 从 GitHub 归档清单核对 S003 / S005 / S006；从接收 SHA 清单核对用户交接包，不改写输入。
- 主解析与官方一致：Pandas 默认 float 解析，canonical 日期 / 股票行序；round_trip 解析、可用的 11 个原生模型重载推理单独作精度 / 并列诊断，不替代正式输入。
- 每个主单元和两种预声明行序敏感性，从真实 CSV 对照未修改官方八指标（1e-10）；逆序 / seed=42 日内置换逐行移动原 CSV 字节，数字不重新序列化。敏感性不进入择模。
- 原 `band_scores(q*)` 只接收键、pred、涨停标志；完整年度冷启动连续递推，核对数值与真实 Top，并做年度前半段真实前缀重放。完整排序 / 并列的差异单独保留；若数值差 >1e-12 或实际 Top 变化则停止该来源。末位精度导致的非头部完整并列差属于诊断，不通过切换解析器隐藏。

## 表格、状态与统计

互斥 0–5 / 5–10 / 10–15 / 15–20 / 20–30 / 30–50 / 50–70 / 70–100% 与累计 Top5/10/20/30 分开；收益池为非涨停、y 有限，换手池为非涨停。真实事件用 y 的平均百分位，ties 同标签。

未来 S010 候选召回诊断先在 **t 日有效价格 + 非涨停** 池按 raw / 代码并列规则选 Top20/30，再核对允许训练标签池的真实 Top10；y 或缺 y 不用于选池。收益池里的排序召回另存，避免把事后可见标签池当成可执行候选池。

留仓分两层：实际 H_turn 的交 / 差集及其标签覆盖；H_ret 按昨日 H_turn 分组，以人数权重还原官方日超额，首日 initial 单列。贡献的年度 / 月度均以完整期间日数为分母，不把首日单个 observation 年化成全年贡献。年度末持仓段右删失；旧 band 没有主动操作日志，规模退出只报已知下界，不编造替换操作。

因果市场序列复用冻结 V1 cache 和 `market_features.py`；只给市场函数传 X，原 y 后接作诊断。波动 / 宽度阈值为外层年份之前的中位数，趋势按 0；真实前缀重算至 2023 年末。股票 amount / volatility_20 为当日已知 X 四分位，缺值单列。

配对区间为 20 交易日循环块、1000 次、seed=42（逐年 seed+year），模型 / 参照使用相同日期；只抽已在连续时间算好的日统计，不在拼接边界重建控制器。分层收益年化、边界 gap 与置信区间均为辅助诊断量，区间不消除多轮历史选择偏差。

诊断分流数值在执行前冻结：Y4 三个 raw CV 年度中至少两个的边界 gap 95% 下界不为正，或 Top20 候选召回 <0.50 / Top30 <0.70，则支持有限 S010 实验。这些是本项目的诊断门槛，不是官方标准或新模型成功证明。S011 需同一 market raw 状态相对 T030 在至少两个 CV 年度具有正超额差、IC 差 ≥−0.005且各有 ≥60 日支持；再由未来严格过去 OOF 的规则检验，2024 不参与该分流。
