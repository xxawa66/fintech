# LH021 折长对齐测试期：344 交易日三窗口复验

日期 2026-10-10 / 分支 `model/long-horizon-rerank` / 未重训模型、未触碰 S003 冻结产物。

## 0. 问题

LH016 §12 的结论是「四折 4/4 折赢、测试期输」。四折每折固定 **242** 个交易日，而测试期
`20250102-20260608` 是 **344** 个交易日。一个自然的怀疑是：**折长不同本身就是反转的来源**
（一年折把 regime 切得太碎，或恰好在 yearly 边界上采样）。本实验把折长改成与测试期
逐日等长，起点分别取 2021/2022/2023 的首个交易日，重算各项评分。

## 1. 设计

| 窗口 | 起止 | 交易日数 |

| S2022 | 20220104–20230606 | 344 |

| （对照）测试期 | 20250102–20260608 | 344 |

- **预测拼接**：三个窗口都跨年。2021 段取 `wf2021` 折模型对该年的样本外预测，
  2022 段取 `wf2022`、2023 段取 `wf2023`、2024 段取 `confirm2024`（
  `outputs/long_horizon/LH003/<fold>/raw_predictions.parquet`）。每段都是「用当年之前的数据
  训练、预测当年」，无前视；跨年处模型会换一次，这是 walk-forward 的固有性质。
- **面板**：`data/raw/训练集.csv` 20210101–20241231，969 个交易日 × 4650 只，与各折缓存按键 merge。
- **对照臂**：C = `H01 + band(q*)`（冻结基线，自检锚点）；A = `H01 + band(0.20)`；
  Bm = `H05_F2T2 > H20_F2T2 q=0.10 + band(0.20)`，mapped 判定；Bc = 同名单源、combo 判定。
  另加三条纯预测（不接 band）作参照。
- **口径**：`src/evaluation/official_eval.py`，`q* = 0.0022778298112255263`（S003 冻结 spec）。
- **必读说明**：三个窗口**互相重叠**（S2021/S2022 共享 2022H1，S2022/S2023 共享 2023H1），
  且全落在与四折相同的 2021–2024 区间。所以它是一个**稳健性族**，不是三个独立折——
  它能回答「折长是不是原因」，不能回答「哪段区间更差」。这也是本实验的定位。

（Bm−C 同口径，242 日四折：ΔIC +0.013924、Δ超额 +0.026769、Δ换手 −0.009519、合计 +0.031174。）

两条观察：

1. **模型自身的绝对水平对折长几乎不敏感**：Bc 的 final 0.414202（242 日）→ 0.413866（344 日），
   差 −0.0003；Bm 0.410969 → 0.411854，差 +0.0009。折长从 242 拉到与测试期逐日等长，
   B 线的分数**没有变化**。
2. **Δ超额项反而随折长变大**（+0.0268 → +0.0328）。折拉长没有削弱模型的顶部超额优势。

顺带一个 C 基线的性质：它的 final 在三个窗口里是 0.3811 / 0.3809 / 0.3604（跨度 0.021），
而其 top1 年化是 0.1798 / 0.1106 / **0.0073**（跨度 0.173）。S2023 窗口里基线几乎选不出
正收益的顶部（top1 ≈ 0），靠换手项仍拿到 0.3604。这与 §9「基线分数来自结构性套利、
不是预测质量」完全一致。

## 6. 结论

1. **折长不是原因。** 把折长从 242 个交易日改成与测试期逐日等长的 344 个交易日，
   三窗口的 Δfinal 是 +0.0368 / +0.0389 / +0.0423（全正），同等换手差 +0.077~+0.105（全正），
   three-term 里只有换手项为负、且与四折同量级。模型的优势在等长窗口下**原样保留**。
2. **反转发生在区间，不在长度。** 三个窗口覆盖 2021-01 → 2024-06，与四折同一区间；
   它们给出与四折一致的结论。测试期落在 2025-01 → 2026-06，是**这段区间**让
   Δ超额项从 +0.033 翻到 −0.018，而不是窗口被切成了多长。
3. **可外推的仍然只有 IC 一项**：ΔIC 项在 242 日四折 +0.0139、344 日三窗口 +0.0139、
   测试期 +0.0147——三个口径逐位一致，这是本项目唯一被反复证实可外推的量。
4. **C 基线的稳健是「分数」的稳健，不是「选股」的稳健**：S2023 窗口里基线 top1 年化只有
   0.0073，final 仍有 0.3604。这也解释了为什么单看 final 会误判两条线的关系。
5. 判据维持 LH016 §12 的建议：**机构层面的对比一律用同等换手口径**，并报告逐窗口符号；
   折长在 242–344 天范围内不是敏感变量（至少对 B 线不是）。
