| 指标 | 结果 |

| ICIR `icir` | 0.6490875703 |
| IC 正值比例 `ic_positive_ratio` | 77.27272727% |
| Top 组年化超额 `annual_excess` | 40.13469790% |
| Top 组年化绝对收益 `top1_annual_ret` | 38.73023280% |
| 平均 Jaccard 换手 `mean_turnover` | 86.39777959% |
| 综合分 `final_score` | **0.1975171338** |

IC 与 Top 指标各有 242 个有效日，换手有 241 个有效日。

`0.4 × 0.0907659471 + 0.3 × 0.4013469790 + 0.3 × (1 − 0.8639777959) = 0.1975171338`。

年化指标按官方算法以日均值乘 252 计算，未经复利或交易成本调整。这是 2024 验证结果；正式测试集没有公开标签，本次未生成正式测试提交。

## 首次失败与修复记录

最初代码提交 `01b015b` 的 `E000_baseline__smoke` 已完成 256 只股票 / 10 轮训练，但 LightGBM 原生接口不能在本机中文目录下保存模型。该失败目录和错误日志保留，未写成功实验行。

提交 `e5f689d` 改用 Python 读写 LightGBM 标准模型文本，增加中文目录与中文文件名的重载检查。之后的 `E000_baseline_retry1__smoke` 和正式全量实验均通过。前置检查用时 23.5 秒，评分与官方一致；此处最终指标表全部来自正式全量运行。
