## 固定协议

50 个联合 trial；40 特征；2021 / 2022 / 2023 扩展窗口；三折共用一个 keep_q；
目标为三折官方综合分等权均值。模型按固定轮数训练，无验证早停、无 pruning。
keep_q 开放 0–1；前十组有八组集中于 0.05–0.15，另两组检查 0 / 1；
完整参数与 band 共同选优，IC 不设额外筛选门槛。每折独立冷启动，行序为日期、股票代码。
