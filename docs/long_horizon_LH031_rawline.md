# LH031：明线与暗线的分离 —— 提交向量里只有 10% 参与交易

> 全程 CV 四折（2021-2024）配对检验 + 用户授权的测试期探索对照（不作选型依据）。
> 脚本 `research/LH031/`，产物 `experiments/LH031/`。自检：部署点四折 × 6 项逐位复现归档 TS_K40。

---

## 1. 起因：一个一直没被拆开的问题

官方三项指标作用在**同一份提交向量**上，但它们各自只看其中一部分：

| 指标 | 实际吃的是哪一段 |
|---|---|
| IC | 逐日**全池** Spearman(pred, y)，只剔 y 缺失 —— **全宇宙** |
| 年化超额 E | top 10% 等权收益 − 有效池均值 —— **只吃 10%** |
| 换手率 T | top 10% 集合的日间 Jaccard —— **只吃 10%** |

也就是说：**提交向量里 90% 的排序不进交易，却被 IC 计分。**

顺着这条往下读 `fast_band`（官方 `turnover.band_scores` 的同构实现），能把它拆得更细。官方编码把提交向量切成**三段，且段间顺序被强制**：

```
band 段     ~10%   在榜股，保留全池分位            -> 最终向量的最上面
nonpool 段  ~60%   候选池（mix top 40%）之外        -> 中间
drop 段     ~30%   池内但落选，整体下移 1 - q*      -> 最下面
```

注意第三段：池内 40% 里没被选中的 30%，**被强制压到全宇宙最底部**，尽管按模型它们排在 10%~40%。这是两阶段编码的固有代价 —— 想让 top10% 由另一条信号选出，就必须先把候选池撑大，多出来的部分只能沉底。

## 2. 三段的自由度：实测界定

把三段各自的排序信号当独立自由度扫（30 变体 × 4 折），结论是**不对称**的：

| 段 | 占全池 | 能否自由重排 | 原因 |
|---|---|---|---|
| **band 段** | ~10% | **不能** | 它的内部次序决定补位顺序（每日约 7 只涨停股滑出后由段内最高分递补）。改序 → 组合变 → E / α / profile / T 全变（实测 ΔE 最大 −0.031） |
| **nonpool 段** | ~60% | **不能** | 换成别的信号会因各模型 NaN 覆盖不同改变可选集 ⇒ `n_elig` 变 ⇒ `n_top` 变 ⇒ 暗线被改动（实测 ΔE 1e-3 ~ 1e-2）。即使做支持集对齐也只能压到 3.6e-3，压不到 0 |
| **drop 段** | ~30% | **完全自由** | 已整体沉底，段内次序对任何交易结果零影响 |

**判据是硬的，不是"看起来接近"**：drop 段换任何信号，`excess / alpha / profile / turnover / hold_days / 十层构成` 相对部署点的四折最大绝对偏差 = **0.000000000**（机器零），只有 `ic` 变。

自检样例（confirm2024，`score_model.py` 官方模块）：

```
DEPLOY      IC 0.082826  E 0.207993  T 0.017997  F 0.390129
rawmix|mix  IC 0.084075  E 0.207993  T 0.017997  F 0.390629
                          ↑ 逐位相同   ↑ 逐位相同
```

## 3. 结果：把 drop 段铺成原始预测

当前 drop 段用的是 **H01 序**（两阶段遗留），而它本该是原始预测。按用户原则「top10% 之外都应该是原始预测结果」执行：

| 变体（drop段｜nonpool段） | ΔIC 四折均值 | 最小折 | t | 逐折符号 | Δfinal |
|---|---|---|---|---|---|
| H01｜mix（= 部署点） | 0.000000 | — | — | — | 0 |
| mix｜mix | +0.001519 | +0.001005 | 7.78 | `++++` | +0.000608 |
| H05_F2T2｜mix | +0.002003 | +0.001145 | 6.14 | `++++` | +0.000801 |
| avg3｜mix | +0.001986 | +0.001197 | 7.05 | `++++` | +0.000794 |
| H05_F1T2｜mix | +0.002034 | +0.001080 | 6.16 | `++++` | +0.000813 |
| **rawmix｜mix** | **+0.002111** | **+0.001251** | **6.57** | `++++` | **+0.000844** |

**留一折选参：四次全部选中 `rawmix|mix`，且它在每一折的未见折 ΔIC 都优于 `mix|mix`。**

（`rawmix` = 三个模型**原始预测值**按部署权重加总后再取百分位；`mix` = 部署用的**分位级**融合。两者都是"原始预测"，差别只在融合发生在原始值层还是分位层。）

## 4. 这个增益的性质（必须说清楚）

**它是明线的改善，不是暗线的改善。** 组合、收益、换手、α、profile 全部逐位不变，变的只是"提交向量的排序质量"这一项被官方 IC 度量的东西。

对数据分析赛道，我的判断是它**值得做但不值得夸大**：

- 值得做：官方 IC 问的是"你的预测向量能不能把股票按未来收益排好序"。drop 段当前用 H01 序，而 H01 在这一段的判别力明显弱于原始预测；改成原始预测后这一段确实排得更对。**这是被度量对象本身的真实改善，不是绕过规则。**
- 不值得夸大：它不改变任何一笔交易。量级也只有 +0.0008（CV）/ +0.0005（测试期）。

## 5. 与已有的三个口径问题并列

这是本项目量出的**第四个评分函数口径问题**，四个都指向同一件事：官方三项指标的评价对象与实际交易对象不一致。

| # | 问题 | 出处 |
|---|---|---|
| 1 | 换手罚项隐含单边成本 0.39%，是 A 股实际的 1.9~3.9 倍 | LH027 |
| 2 | IC 的评价域含当日涨停股（买不到），占官方 IC 的 6.22% | LH028 |
| 3 | α 与 profile 打包成同一个 E 给同一 0.3 系数，不区分收益来源的可外推性 | LH030 |
| 4 | IC 的评价对象是全池，但只有 10% 参与交易；另有 30% 被强制沉底 | 本轮 |

## 6. 边界

- **0.4 仍不可达。** LH026 的算术没变：换手项已饱和在 0.29475，要拿 0.4 需 IC ≥ 0.109（保守 0.119），而官方通常上限是 0.1。本轮回收的 +0.0021 只占那个缺口（+0.023~+0.033）的 6%~9%。
- **两阶段编码的 IC 代价不可完全消除。** 纯 mix 的全池 IC 是 0.10649，TS_K40 是 0.08630，差 0.020。其中只有约 0.002 是"排序没排好"（本轮回收），剩下约 0.018 是"30% 被强制沉底"的位移代价 —— 只要还想让 top10% 由另一条信号选出，这部分就必然存在。
- **drop 段的候选信号已扫过 6 个**（H01 / mix / F1T2 / F2T2 / avg3 / rawmix），彼此差距在噪声内（ΔIC 差 ≤ 0.0006）。不再加密网格。
