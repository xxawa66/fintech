# LH020 —— E 的因子归因与两阶段模型

> 目标：解释「为什么长周期模型四折更好、测试期更差」，并给出一个**机制上**更可能提升的模型。
> 选型只用 ≤2024 的四个 CV 折；测试期只用于**验证已由 CV 锁定的单一设计的机制**。

---

## 0. 一句话结论

长周期模型从来没有更强的选股能力。它在四折上多出来的「年化超额」，是**低波动风格押注**的收益；
低波动溢价在 2024H2 断档，押注随之归零。把「选股能力」和「风格押注」分开后，
前者（α）低于基线 H01，后者（profile）不可外推。
据此设计的**两阶段模型**（长周期负责全池排序拿 IC、H01 负责头部拿 α）是本项目第一个
**CV 分数与测试期分数几乎相等**的模型（落差 −0.0014，基线 −0.0060，LH019 −0.0376）。

---

## 1. 归因方法：把 E 精确拆成 α + profile

时间序列回归不可用：5 个因子收益高度共线，β 在折间符号翻转，α 不可信。
改用逐日横截面分层（DGTW 式），按 **vol60 十层**把名单超额精确分解：

```
excess_t = Σ_b w_b^B · ( 名单在层 b 的收益 − 层 b 收益 )        ← α：组内选股
         + Σ_b ( w_b^B − w_b^V ) · ( 层 b 收益 − 市场收益 )     ← profile：因子轮廓
```

- **α**：在同类（同波动率层）股票里是否挑到了更好的。**不依赖该层的收益水平**，
  因此不受「低波溢价还在不在」影响。
- **profile**：名单落在哪些层 × 那些层的收益。**完全由因子溢价决定**，溢价一变就变。

分解是恒等式（不是拟合），两项相加精确等于官方 E。

因子只用历史数据构造：`log_amt`（20 日成交额均值取对数）、`vol60`（60 日收益标准差）、
`mom60`（60 日涨幅）、`rev1`（当日收益）、`log_price`（价格对数）。

## 2. 结果：四折 vs 测试期

| 变体 | α 四折 | α 测试期 | profile 四折 | profile 测试期 | E 四折 | E 测试期 |
|---|---|---|---|---|---|---|
| **H01（基线）** | **0.1844** | **0.1911** | +0.0004 | −0.0113 | 0.1907 | 0.1791 |
| H05_F1T2 | 0.1109 | 0.1053 | +0.0812 | +0.0172 | 0.2014 | 0.1205 |
| H05_F2T2 | 0.1198 | 0.0668 | +0.0900 | −0.0014 | 0.2160 | 0.0730 |
| LH019 λ=0.5 | 0.1437 | 0.0871 | +0.0735 | +0.0154 | 0.2255 | 0.1027 |

三条结论：

1. **H01 不做风格押注**（profile ≈ 0），E 全部来自 α，而 α 在四折与测试期间几乎不变
   （0.1844 → 0.1911，差 +0.007）。这就是基线 5 个时期都稳的原因。
2. **长周期家族的 α 比 H01 低 0.041 ~ 0.074**。它在四折上 E 更高，靠的是
   profile +0.074 ~ +0.090。
3. **profile 在测试期塌到 ≈ 0**（0.074 → 0.015）。于是只剩更低的 α ⇒ E 反而更低。

⇒ **长周期模型的「选股」实际上做的是「买低波动」。**

## 3. 为什么低波押注在 2021–2024 赚钱、2025–2026 不赚

低波动溢价 =（波动率最高 30% 的等权收益）−（最低 30% 的等权收益），年化：

| 半年 | 2021H1 | 2021H2 | 2022H1 | 2022H2 | 2023H1 | 2023H2 | 2024H1 | 2024H2 | 2025H1 | 2025H2 | 2026H1 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 低波溢价 | −0.296 | −0.318 | −0.470 | −0.328 | −0.228 | −0.346 | −0.454 | **−0.040** | **−0.090** | **−0.137** | **−0.021** |

（负值 = 低波动跑赢高波动。）

- 2018–2024 连续 **7 年**为负：−0.142 / −0.257 / −0.253 / −0.307 / −0.397 / −0.288 / −0.240，均值 **−0.269**。
- 2024H2 起连续 **3 个半年**只有 −0.04 ~ −0.14。
- 11 个半年里幅度最小的 3 个恰好是最后 3 个：随机排列下 p = 1/C(11,3) = **0.006**。

**这是断档，不是噪声。** 同期名单暴露却极稳：

| 变体 | exp_vol60（名单相对全市场分位，0 为中性） |
|---|---|
| H01 | +0.065 / −0.081 / +0.061 / +0.024 / +0.085 |
| H05_F1T2 | −0.107 / −0.208 / −0.153 / −0.147 / −0.208 |
| H05_F2T2 | −0.085 / −0.251 / −0.193 / −0.089 / −0.276 |
| LH019 | −0.054 / −0.226 / −0.132 / −0.062 / −0.204 |

（顺序：wf2021 / wf2022 / wf2023 / confirm2024 / 测试期）

暴露稳定、溢价断档 ⇒ 四折上测到的 E 优势必然反转。**这不靠运气，也不靠自由度——
它是可事先识别的机制。** 我此前 LH018 把它归为「自由度不足」是不完整的：
自由度只解释了「四折分辨不了」，没有指出「分辨不了的那个东西是什么」。现在它有了名字。

**IC 与 α 是两回事**：IC 是全池 Spearman，由中段（约 60% 样本）主导；
α 只看头部同层内选优。多 horizon 标签降噪提升了**全池**排序（IC +0.028，两次外推证实），
但在**头部**反而更差。**「IC 高」不等于「会挑赢家」**——这是本项目最贵的教训。

## 4. 两阶段模型

机制 ⇒ 设计：把两件事交给各自擅长的信号。

```
阶段 1（粗筛，拿 IC）：长周期融合信号决定谁进候选池（top K%）
                      ⇒ bottom (100−K)% 的排序由它决定 ⇒ 保留已证实的 IC 增益
阶段 2（精排，拿 α）：候选池内改用 H01 排序，最终 top 10% 全部出自 H01 的排序
                      ⇒ 拿到 H01 的 α 与 ≈0 的因子轮廓
```

K=10 退化为纯长周期，K=100 退化为纯 H01。

## 5. 推荐配置

```
# 输入：三套**原始**（未过 band）预测 —— H01 / H05_F1T2 / H05_F2T2，逐日截面

mix   = 0.5000·pct_rank(H01) + 0.1204·pct_rank(H05_F1T2) + 0.3796·pct_rank(H05_F2T2)

# 阶段 1 粗筛
cand  = mix 的分位 ≥ 60%                      # 即 top 40%

# 阶段 2 精排
score = 1 + pct_rank_within(cand, H01)        # 候选池内按 H01 重排，落在 [1,2]
      = pct_rank(mix)                         # 非候选，落在 [0,1]

pred_final = band_scores(score, keep_q = 0.0022778298112255263)
```

部署只需三套现成的测试期原始预测，无需重训：
`t030_test_run/test_pred_T030_raw.csv`、`h05_variants_test_run/test_pred_H05_F{1,2}T2_raw.csv`。

## 6. 离 0.4 还有多远

换手项已到定义下限（TS_K40 换手 0.0184 ⇒ 该项 0.2945，上限 ≈0.2958）。
需 `0.4·IC + 0.3·E ≥ 0.1055`。TS_K40 测试期是 `0.4×0.0828 + 0.3×0.2080 = 0.0955`，**缺口 0.0100**。

换算成 E：在 IC = 0.086 不变的前提下，需要 **E ≥ 0.237**，即 α ≈ 0.237
（当前 0.189）⇒ **选股能力还要再提升 25%**。
**0.4 只能靠把 α 做上去，靠换模型、调权重、压换手都到不了。**

接下来真正值得做的只有一件事：**直接以 α 为目标做留一折优化**（而不是以 IC 为目标）。
α 是唯一既可外推、又真正决定 E 的量，此前所有优化都没把它放进目标函数。

## 7. 必须写进报告的诚实声明

1. 全部设计决策（K=40、两阶段结构、可外推口径）都在**四折**上做出；
   测试期只跑了一次已锁定的设计，用于验证机制。
2. 测试期已被前 14 轮约 90 个方案用过，**不再是干净的样本外**。
   「TS_K40 测试期 0.3901」应被当作**机制验证**，不是独立证据。
3. 真正独立的证据是两条：① α 与 profile 的分解是恒等式，且 H01 的 α 跨 5 个时期稳定；
   ② CV→测试期的落差从 −0.0376 收敛到 −0.0014，说明 CV 分数不再是风格红利的载体。
4. K=40 不是「最优」，是可外推口径下的 CV 最优点；K=30~50 之间差异 0.002，
   处于噪声级，不做结论。
