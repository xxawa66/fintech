- 时间验证切分（阶段 3，2026-10-05，成员 B）：`src/evaluation/validation.py` 实现固定窗口切分（fold1 训练 2018–2022 / 验证 2023；fold2 训练 2018–2023 / 验证 2024；final 全量 2018–2024 / 预测 2025–2026），折定义集中在 `configs/project.yaml` 的 `validation` 段。核心规则：**训练窗口最后一个交易日（其标签由验证期首个交易日收盘价计算）的标签在切分时置 NaN**，训练侧按“删除无标签样本”处理。`--check` 在真实数据上核对：fold1 剔除 4,280 个跨界标签（20221230 的标签完全等于 close(20230103)/close(20221230)−1，逐行核验一致）、fold2 剔除 4,522 个；训练/验证日期无重叠且落在各自窗口内；测试集 1,599,600 行全部落在预测窗口 [20250102, 20260608] 内。
