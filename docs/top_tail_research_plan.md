## 4. S009：零训练的 Top-tail 与误差诊断

### 4.1 来源与口径核对

1. 核对原始训练数据 / 官方附件、S003 / S005 / S006 来源摘要及输入接收 SHA；核对交接包 spec 与各自仓库 summary / S008 selection。
2. 每份预测从 CSV 重读，检查全部期内键、唯一性、有限值、股票代码保留、日期及 `trade_date,ts_code` 行序。先保存原生精度与实际并列信息，不能静默换一种解析器改变顺序。
3. 以原始 `y_ret_1d` 评分；与未改动 `evaluate.py` 核对八指标，最大差不超过 1e-10；与既有记录核对，差异公开。
4. raw → 原 `band_scores(q*)` 在每年冷启动，完整年内保持状态，核对已交接 band 的实际排序 / Top 集合 / 分数；不按月重置。来源解析或保存差异先记录，不篡改文件去迎合指标。
5. 缺文件、键或分数不一致时保留失败证据，暂停受影响模型的后续比较；不自动调用 S007/S008 主入口重训。

官方池保持分开：IC 仅删除缺 y；收益 Top 删除涨停与缺 y；换手 Top 只删除涨停。控制器不能接收 y 或其缺失掩码。收益 Top 的 `N//10` 与换手 Top 的规模可能不同，不能用一个集合替代另一集合。

### 4.2 每日头部分层与边界

分别对 raw / q* 层，在官方收益池按实际 pred 顺序分为互不重叠的 **0–5%、5–10%、10–15%、15–20%、20–30%、30–50%、50–70%、70–100%**；另报累计 Top5/10/20/30%。边界按整数样本数确定，记录跨档精确并列组。

输出日 / 月 / 季 / 年：样本数、真实均值、中位数、日均超额 × 252、正收益 / 正超额比例、分层单调性。重点比较 **5–10% vs 10–15%**；这些是诊断量，不能伪装成官方新增指标。

再计算真实高收益 Top10 / Top20 事件的 Precision@10、Recall@20 / @30、收益幅度及头部重叠。二分类事件只是未来收益排名标签，不等同于最大期望超额收益；只有捕获比例提高还不足以证明能提官方分。

### 4.3 精确并列与缺价兜底

记录每日最大并列组、并列股票比例、并列值、原生 / CSV 精确并列差、Top10 边界并列人数、零预测的排名位置；用 t 日有效价格标记区分缺价兜底与模型真实输出 0。优先核对 S005 中提到的并列是否真的接近头部，不直接沿用“约 429 个 ties 就是问题”的判断。

固定原预测，描述三种行序：原 canonical、日内代码逆序、seed=42 的日内置换。敏感性结果只说明原并列处理的影响，不能挑得分最高的行序做正式方案；未来正式输出固定 canonical。不添加随机抖动或依据真实收益打破并列。

### 4.4 留仓与换入收益

保留两个实际集合：`H_turn(t)` 为官方换手 Top，`H_ret(t)` 为官方收益 Top。

- 对 `H_turn(t)` 分成与昨日集合的交集（留仓）和差集（换入），记录完整数量、标签覆盖、可评分收益、持仓长度和当日 raw 排名；这组收益不直接代替官方 Top 收益。
- 对 `H_ret(t)` 按是否属于昨日 `H_turn(t-1)` 分组，按当日各组人数加权，精确还原官方 Top 平均收益与超额。首日单列，不当作正常换入日。
- 分开记录主动替换、涨停导致的不合格退出、规模变化等；换出后收益仅作事后诊断，不进入控制器。

这样能够区分“当前信号换入质量弱”“旧持仓贡献主要收益”“两种官方池造成差异”三种情况，不把整个 band 的效果简单归为留仓过久。

### 4.5 状态互补与统计不确定性

按过去数据界定高 / 低市场波动、市场宽度及趋势状态；股票流动性用当日 amount 的横截面分组，股票波动用历史 `volatility_20`。不得用未来 y、2024 全年分位数或年份标签定义当天状态。

逐日比较 T030 / Y1 / Y4 / market / T033 的 raw 与 q* 超额、IC、Top 重合和分项差；同时给出样本日数。先看互补性是否在 2021–2023 多段出现，再展示 2024 的历史诊断；不能从“2024 market 更好”直接写出选择 market 的门控规则。

采用 **20 交易日块、1000 次、seed=42 的配对 block bootstrap**，逐年内重采样，同一次抽样对参照与模型使用相同日期，报告 ΔScore / ΔExcess 的 95% 区间。日 IC / 超额 / 换手先在原连续时间与实际状态上计算，bootstrap 只抽这些配对日统计；不在拼接块边界重跑控制器制造额外换手。各指标的缺失日按官方各自有效样本处理，年度结果等权汇总。

置信区间是固定历史样本下的条件描述，不消除既往择模、多个候选筛选和历史市场变化的偏差。S009 的显著性结果用于判断证据强弱，不为已有模型补造独立留出。

## 5. S010：有限的头部分类与两阶段排序

### 5.1 固定第一阶段与五个实验臂

第一阶段固定 **Y4**（S005 的训练目标、T030 参数、800 轮）。其作用是提供全市场粗排序及一个百分位特征，不在本轮重新选目标或搜索参数。

|编号|第二阶段训练样本|目标|第二阶段特征|
|---|---|---|---|
|B10|全部允许训练样本|明日真实收益 Top10% 二分类|V1 40 + 第一阶段 OOF 百分位，共 41|
|B20|全部允许训练样本|明日真实收益 Top20% 二分类|同上|
|R20|第一阶段预测 Top20% 候选|真实全市场 Top10% 二分类|同上|
|R30|第一阶段预测 Top30% 候选|真实全市场 Top10% 二分类|同上|
|L30|第一阶段预测 Top30% 候选|全市场收益五级序数 + LambdaRank|同上|

这五臂分别检验标签、筛池和排序目标；不扩展模型网格，不自动加融合权重。B10 / B20 也使用 OOF 分数，作为“不筛池”的一致对照。全部第二阶段从 2019 起训练，避免与筛池臂训练可用时期不同；报告与原 2018 起训的 T030 / Y4 比较时说明该差别，不能将全部变化只归因于损失函数。

### 5.2 标签与样本规则

每个外层训练窗口先剔除跨界标签。训练标签横截面只用有效价格、`flag_limit_up==0`、原始 y 有限的允许监督行；按每日 y 的平均百分位定义 `p_y`。

- B10 / R20 / R30：`p_y > 0.90`；B20：`p_y > 0.80`。边界相同收益保留平均并列，不按代码给不同真标签；记录实际正例比例及单类日期。
- L30：按 0.60 / 0.80 / 0.90 / 0.95 分为整数 0–4，`label_gain=[0,1,2,3,4]`；保持 ties 的同标签。
- 标签在全允许监督池定义，然后才按 OOF 预测取候选；不能把“候选池内 Top10%”误当成“全市场 Top10%”。
- 候选由当日 X、第一阶段预测和既有涨停 / 有效价格标记形成，不看 y 或缺 y 掩码；训练时取候选后才移除没有监督标签的行。

二分类概率和序数相关性均不是官方收益金额目标，必须保留真实超额对照。LightGBM 支持 binary / lambdarank；排名标签和分组要求按[官方参数说明](https://lightgbm.readthedocs.io/en/stable/Parameters.html)落实。

### 5.3 严格按时间生成 OOF

OOF 指预测该日期时，第一阶段模型没有用过该日期及之后的标签。第二阶段训练池必须来自这种时间外预测；不能从第一阶段对自身拟合样本的预测筛选训练池。

需补充两次第一阶段预热拟合，均固定 Y4：2018 → 预测 2019、2018–2019 → 预测 2020。2018 没有更早训练历史，不生成伪 OOF，不纳入第二阶段。

|外层验证|第一阶段训练 / 当期预测|第二阶段可使用的历史 OOF|
|---|---|---|
|2021|2018–2020 → 2021（复用 S005）|2019、2020|
|2022|2018–2021 → 2022（复用 S005）|2019–2021|
|2023|2018–2022 → 2023（复用 S005）|2019–2022|
|2024，唯一锁定方案|2018–2023 → 2024（复用 S006 Y4）|2019–2023|

内层第一阶段训练、外层第二阶段训练均屏蔽其各自跨验证边界的标签；OOF 的模型 / 标签 / 目标映射 / 日期 / SHA 全部记录。2022 / 2023 的 OOF 不能进入 2021 的第二阶段，即使它们已存在磁盘上。旧 Y4 参数本身是经历史研究选择的，嵌套训练边界正确仍不意味着消除过去模型选择偏差。

按交易日切分，复用本项目的日期与标签边界逻辑；不能对股票行直接随机 KFold，也不能把按“行数”计算的 gap 当成按交易日 purge。时间先后原则见 [TimeSeriesSplit 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)。

### 5.4 模型、完整输出与预算

全部第二阶段固定 400 轮、seed=42、CPU 8 线程，树结构 / 正则 / 采样参数沿用 T030；只按任务换 objective / metric，binary 不启用自动类别加权，不使用外层验证早停。L30 按 `trade_date,ts_code` 连续排组，group 数组为每日样本数、总和等于样本数；截断层固定 466，接近 4650 股票全市场 10% 的规模，另报各日实际 Top 数，不搜索截断值。NDCG 仅为辅助量。分组规范见 [Dataset 官方说明](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.Dataset.html)。

B10 / B20 预测全市场有效价格行，缺价保持记录明确的原始 0 兜底；所有键都输出。R20 / R30 / L30 在候选池内按第二阶段分数排序，池外保留第一阶段相对顺序；候选整体在池外之前。候选边界并列按预声明代码顺序取固定人数，第二阶段精确并列以第一阶段分数为第二排序项，仍相同则保留并列。完整分数按预定单调排名编码保存，检查原生 / CSV 顺序与并列一致，原生数值另存无损文件。IC 在全市场算，不只在池内算。

所有完整信号最后叠加**一次原 q* band**，每年冷启动；控制器作用于完整信号，历史留仓不因今天掉出候选池而被额外强制清空。raw / q* 都保存并评分，但正式晋级以完整 q* 方案为准。

上限：预热 Y4 **2 次** + 五臂 × 三折 **15 次** + 唯一锁定臂的 2024 第二阶段 **1 次** = **18 次新增模型拟合**。第一阶段当期预测都按来源核对后复用；没有合格臂时不执行最后一次。失败拟合计入预算；不自动重试，不补训 Y1 的 2024。若预热产物已精确可验证可复用，实际次数下降，不能把节省预算自动转成新搜索。

## 6. S011：极简、按过去 OOF 学习的状态门控

主 expert A 固定 T030，expert B 固定 S007-market。使用它们的 raw 日百分位排名融合，再统一过一次 q* band；不能先对各 expert 分别 band 后混合，也不能把各自旧持仓收益拼成门控收益。

有限矩阵共 **6 个策略**：

|编号|策略|market 权重|
|---|---|---|
|G0|T030 参照|0|
|G1|静态排名融合|0.25|
|G2|静态排名融合|0.50|
|G3|20 日市场波动高 / 低两状态|每状态只取 0 或 0.25|
|G4|20 日市场宽度高 / 低两状态|同上|
|G5|20 日市场动量正 / 非正两状态|同上|

高 / 低阈值为该外层年份之前因果市场序列的历史中位数，趋势阈值为 0；阈值、状态权重映射按年冻结，当天状态仅用 t 日及以前 X。高 / 低按预声明 `>` 划分；缺状态值回退 A。

状态权重只由**更早年度**的 expert OOF raw 日超额差学习：每个状态至少 60 个有效日；过去配对块抽样的 B−A 超额 95% 下界 >0，且该状态 raw IC 均值差 ≥−0.005，才允许权重 0.25，否则 0。不用同年的验证收益决定当年的权重。

|门控预测期|可用于 expert 表现学习的历史|
|---|---|
|2021|当前没有 2019–2020 market OOF：所有状态默认 A，作为暖启动参照|
|2022|2021 OOF，移除标签跨入 2022 的边界日期|
|2023|2021–2022 OOF，屏蔽当期边界|
|2024，锁定后历史检查|2021–2023 OOF，屏蔽当期边界|

2021 的退回 A 必须单列，不能宣称三年都完成了门控学习；主要同时报告 2022–2023 的学习期表现与完整三折规则回测。状态差的训练 bootstrap 在过去完整日序列抽块，再按状态取样，不能随机打散股票行。

本轮只用已保存预测做策略比较，**0 次新股票模型拟合**；门控历史均值 / 区间学习仍要记录，是标签使用，不等于无监督规则。六策略 × 三折上限 18 个完整配置，G0 / 相同排序复用去重；只把一个 CV 合格策略锁定后做 2024 检查。所有门控完整信号连续运行，月末不清空状态。

若状态互补不能重复、低样本状态太多或 G1/G2 已解释全部收益，报告无可靠动态门控证据，保留 S003。正式生产使用 market 模型需要后续另行训练与保存；当前零拟合策略实验不具备完整模型生产交付。

## 7. 稳健晋级与停止规则

以下数值是**预定研究门槛**，不保证隐藏测试结果；实施时在看到新臂分数之前进入独立配置并提交。原 S003/S006/S008 选择清单不改写。

### 三折选优，锁定一个完整方案

- 2021–2023 等权 ΔFinal ≥ **+0.003**、等权 ΔAnnualExcess ≥ **+0.01**。
- 至少 **2/3 年**超额提高；每年超额不低于参照−0.02。
- 2023 与最差年度综合分不低于参照−0.005；逐年 IC 至少保留参照的 95%，平均换手不超过参照 +0.01。
- 36 个月正超额比例不下降；各自最差 10% 月份（向上取整 4 个月）的综合分均值不低于参照−0.005。
- 配对块抽样的 ΔFinal / ΔAnnualExcess 95% 下界均 >0；公开全部五臂 / 六策略，区间不当作多轮历史择模后的显著性证明。

合格池按最高官方均值，1e-6 内按更高最差折、更少组成模型、预定编号。S011 也与静态 G1/G2 对照，没有动态超额改善不称门控机制有效。无合格方案直接保留 S003。

### 先推送清单，再报告已使用过的 2024

锁定模型 / 目标 / OOF 来源 / 池比例 / 编码 / 控制器 / 状态阈值与学习规则，先提交、推送 main；2024 的新预测或门控完整结果之后才生成。S009 允许看历史 2024 做预声明诊断，后续的这一检查明确为**历史压力检查，不是独立留出**。

锁定方案 2024 综合分不低于 S003−1e-6、超额不低于参照−0.02、IC 保留 ≥95%、换手不超过参照 +0.01；同时四年等权 ΔFinal ≥+0.003、ΔAnnualExcess ≥+0.01，至少 **3/4 年**超额提高，48 个月正超额比例不下降、最差 10% 月份（5 个月）不明显退化。完整报告四年区间、所有年度及全部月份。

任何一条未达门槛则保留 S003，不在已看 2024 后换成另一个臂、池比例、权重或状态规则。晋级只交接 B 复核，团队确定正式采用。2021–2024 均被多轮研究使用；没有未触碰的新留出可以证明未知泛化。2025–2026 不参与选择、标签推导或调参；正式测试分仍待官方隐藏标签。
