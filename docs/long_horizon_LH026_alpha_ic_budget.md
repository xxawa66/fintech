# LH026 —— α 的容量与 IC 的门槛：把「优先优化 α」量化成一条不等式

> 触发：用户给出两条外部信息——① 官方口径 **IC 的通常上限是 0.1**；② 优先级是 **尽量优化超额里的 α**，IC 也不是完全没机会。
> 本轮回答：**α 这条路还剩多少、IC 需要多少才能补上缺口。**
>
> 本轮**没有重训任何模型**，全部结论来自对已有四折/八窗口结果的重新判读与代数演算。
> **不引用任何 2025 年以后（测试期）的数字做选型或论证。**

---

## 0. 一句话结论

**α 已经到顶：可达上界 0.1916，比部署点只高 +0.0027，且这个增量统计上不可见（α 的配对标准误 0.00173，折间 sd 0.033~0.064）。**

把 α 打满之后反解门槛：**要拿 0.4 分，IC 必须 ≥ 0.109（乐观）~ 0.119（保守），即必须超过官方说的「通常上限 0.1」9%~19%。** 换句话说，α 这条路走到头之后，缺口**全部**落在 IC 上，而 IC 需要的幅度已经越过了官方声称的上限。

同时本轮补上了 α 不可优化的**第 5 条独立证据，且是第一条跨信号源的证据**（LH023 只在权重微调轴上证明过）。

---

## 1. 预算方程

官方 $ \mathrm{final} = 0.4\,\mathrm{IC} + 0.3\,E + 0.3\,(1-T)$，$E = \alpha + \mathrm{profile}$。

换手项已贴定义下限（涨停股必然滑出）：$T \ge 0.0175 \Rightarrow 0.3(1-T) \le 0.29475$，剩余空间 ≈ 0.0003 分，**该项已饱和，不再进入讨论**。

于是硬约束是：

$$
0.4\,\mathrm{IC} + 0.3\,E \;\ge\; 0.4 - 0.29475 \;=\; 0.10525
$$

---

## 2. α 的容量：可达上界 0.1916，比部署点高 +0.0027

### 2.1 可达上界

在换手不炸的可达空间内，四折均值 α 的最高值：

| 来源 | 最高 α（四折均值） | 位置 |
|---|---|---|
| LH023 λ×K 联合网格（74 组合） | **0.19159** | (λ, K) = (0.5, 42) |
| LH023 K 轴（步长 10） | 0.19094 | K = 45 |
| LH023 λ 轴 | 0.19068 | λ = 0.6 |
| LH025 band 留存规则（36 配置） | 0.1889 量级 | 部署点本身最高 |
| **部署点 TS_K40** | **0.18886** | — |

⇒ **Δα 可达上界 = +0.0027，仅为保守缺口的 5.8%。**（LH023 §8.2 四条轴口径）

α 高的配置（LH025 的 `lkeep|0.08` α=0.2532、`relent|0.6` α=0.2600）**全部是换手炸掉的**：前者 T=0.0815，后者 T≈0.28。这与 LH023 §9 的 corr(final, α) = −0.725 是同一件事。

### 2.2 第 5 条独立证据：换信号源也救不了 α 的可优化性

LH023 §7.2 的「α 剖面跨折秩相关 +0.196（IC 是 +0.961）」是在**权重微调轴**上测的。本轮补的是**跨信号源轴**——L2X（全新 LGBM + 8 个新特征，不是权重调整）与 H01 的混合权重 $w$（`experiments/LH024/cv_design_audit/newfeat_blend_windows.csv`，8 个半年窗口，按 n_days 加权聚合到 4 折）：

| 折 | α 最高点的 w | w=0（纯 L2X）相对 w=1（H01）的 Δα |
|---|---|---|
| wf2021 | 0.1 | **+0.0286** |
| wf2022 | 1.0 | **−0.0664** |
| wf2023 | 0.4 | **+0.1134** |
| confirm2024 | 0.6 | **−0.0349** |

- α 的 argmax 在四折上是 **0.1 / 1.0 / 0.4 / 0.6**——到处跑。
- Δα 符号 **2 正 2 负**，均值 +0.0102，折间 sd ≈ 0.072 ⇒ $t \approx 0.31$，**完全不显著**。
- 以 α 为目标做留一折选参，选出的 w 是 0.6 / 0.6 / 0.8 / 0.4，未见折 Δα = **+0.021 / −0.054 / +0.051 / −0.006（2 正 2 负，符号都不一致）**。

⇒ **换一个全新的信号源，α 的权重剖面依然不可复现。** LH023 的结论不是「权重轴的局部性质」，是 α 这个量本身的性质。

### 2.3 为什么 α 不可优化（量级对比）

| 量 | 值 |
|---|---|
| α 的折间 sd（部署点 / L2X） | 0.033 / **0.064** |
| α 的配对标准误 | 0.00173 |
| 可达的 Δα（四条轴加起来） | **+0.0054** |
| 保守缺口需要的 Δα | **+0.0469** |

⇒ 要「看见」一个 Δα，它得大于 0.03；而所有可达的 Δα ≤ 0.005。**信噪比约 1:6 ~ 1:12。**

**但 α 的「水平」是可外推的**（H01 跨五个时期 0.1844 → 0.1911；长周期家族系统性低 0.041~0.074）。所以 α 只能通过**换一个 α 水平更高的结构**来抬，不能通过在现有结构上以 α 为目标调优来抬——而当前所有已跑结构里，α 水平最高的就是 H01（≈0.19），TS_K40 与之持平。

## 3. IC 的门槛：必须 ≥ 0.109，即超过官方上限

把 α 打满到 0.1916，反解 0.4·IC + 0.3·E ≥ 0.10525：

| 口径 | profile 假设 | 需要的 IC | 相对部署 IC 0.0863 的 ΔIC |
|---|---|---|---|
| **保守**（profile 归零，LH020 已证其会塌） | 0 | **≥ 0.11943** | **+0.0331**（相对 +38%） |
| 乐观（profile 维持 CV 的 0.0136） | 0.0136 | **≥ 0.10923** | **+0.0229**（相对 +27%） |

**注意这个上界已经是「打破 IC–α 负相关」的乐观上界**：LH023 §9 实测 corr(final, α) = −0.725、corr(α, profile) = −0.963，即 IC 抬上去时 α 会掉。上面的计算假设两者可以同时打满，所以真实门槛只会更高。

### 3.1 直接验证：IC 打到官方上限也不够

LH023 §3 的 λ×K 网格里已经有 IC 达到官方上限的点：

| 组合 | IC | α | E（含 profile） | 0.4·IC + 0.3·E |
|---|---|---|---|---|
| IC 最高 (λ=0.2, K=15) | **0.10039** | 0.14279 | 0.21066 | **0.10335** |
| α 最高 (λ=0.5, K=42) | 0.08554 | **0.19159** | 0.20876 | 0.10109 |
| 部署 (λ=0.5, K=40) | 0.08632 | 0.18860 | 0.20831 | 0.10119 |

**IC = 0.10039（已抵达官方声称的通常上限）的那一点，0.4·IC + 0.3·E 只有 0.10335，距 0.10525 仍差 0.00190。** 差的正是它把 α 卖掉换成的 profile（0.06050），而 profile 是 LH020 用半年频率直接验证过、在 2024H2 后会断档的那一项。

⇒ **「官方 IC 上限 0.1」与「0.4 分」在这套结构下不兼容。** 二者只能取其一。

## 4. IC 通道的真实幅度：L2X 案例（与实测的一致性）

IC 是唯一可外推、可被四折分辨的通道，这一点 L2X 轴给出了迄今最干净的样本：

| | w=0（纯 L2X）相对 w=1（H01） |
|---|---|
| **ΔIC** | +0.0037 / +0.0017 / +0.0165 / +0.0038，**四折同号**，均值 **+0.0064** |
| 留一折选参 | 以 IC 为目标，**4/4 全部选中 w=0**，未见折 ΔIC 四折同号 |
| Δ换手 | −0.0035 / −0.0026 / −0.0012 / −0.0024，**四折同号**（换手也降） |
| Δα | +0.029 / −0.066 / +0.113 / −0.035，**2 正 2 负** |
| Δfinal | +0.0103 / −0.0097 / +0.0548 / −0.0168，**2 正 2 负** |

⇒ **ΔIC 外推成功（第 3 次独立复现），Δfinal 不外推。** 这是「IC 高 ≠ 会挑赢家」最干净的一次量化。

### 4.1 但幅度不够，这正好解释了实测的「几乎不变」

ΔIC 的 +0.0064 被 **wf2023 一个折主导**（+0.0165，是其余三折的 4~10 倍）。剔除 wf2023 后：

$$
\Delta\mathrm{IC} \approx (+0.0037 + 0.0017 + 0.0038)/3 = +0.0031
$$

折算成分数：$0.4 \times 0.0031 = +0.0012$ 分，再加换手项 $0.3 \times 0.0024 = +0.0007$ 分 ⇒ **合计 ≈ +0.0019 分**。

**这与「改 w 大幅提高 23 折、测试期评分几乎不变」完全吻合，而且不需要引入任何新的异常来解释**：+0.002 分量级本来就是「几乎不变」。wf2023 的 +0.055（final）是一个离群折的增益，不是普遍能力。

（口径提醒：该 CV 的 L2X 是「折内 30%/60% 天数训练 + 500 轮」，与部署协议「全训练窗 + 800 轮」不同，且只评每折的半年窗口。这是 LH024 遗留的已知漏洞，本轮未修补。）

## 5. 结论

1. **α 作为优化目标：关闭。** 第 5 条独立证据（跨信号源轴）确认 α 的剖面不可复现；可达 Δα +0.0054 对缺口 +0.0469 杯水车薪，且统计上不可见。
2. **α 作为结构属性：已到顶。** 当前信息集（纯量价 + 这套模型族）下 α 的水平天花板 ≈ 0.19，最高的结构就是 H01，TS_K40 与之持平。要抬它只能换信息集。
3. **缺口全部落到 IC 上，且门槛越过官方上限**：需要 IC ≥ 0.109~0.119，即比官方「通常上限 0.1」再高 9%~19%。
4. **单个新信号源能给的 ΔIC 只有 +0.003 量级**（L2X 剔除离群折后）。要凑到 +0.023~+0.033，需要 8~11 个**相互独立**的源且完全可加 —— 而 LH024 已证明在量价信息内造不出真正独立的新源（|IC| 最大的新特征全是 vol60 的克隆）。
5. ⇒ **在「IC ≤ 0.1、α ≤ 0.19、换手 ≥ 0.0175」这组约束下，0.4 分代数不可达。** 这不是调参问题，是约束之间本身不自洽。

### 5.1 还能做的（按期望值排序）

- **甲. 接受 0.39 量级，TS_K40 定稿。** 三轮扫描 100+ 配置，官方 final 的 argmax 始终是它。
- **乙. 若一定要冲 IC：唯一有依据的动法是「跨源 ΔIC 的可加性」。** LH024 §5 只在**特征层面**证明可加（0.00035 + 0.00172 ≈ 0.00206），没有证明**跨模型源**可加。要检验必须造第三个独立源并重训，而 LH024 已说明量价内造不出。⇒ 期望值低。
- **丙. 换信息集。** 只有量价时 α 天花板 0.19 是硬的；引入行业 / 基本面 / 资金流才可能同时抬 α 与 IC。

### 5.2 不作数的方向

以 α/E 为目标的任何调优、加密超参网格、band 的任何变体（LH025 已封死）、靠 profile 换分（LH020 已证其断档）、继续扩大新特征族。
