## 来源与时间

复用 S009 已 SHA / 原生重载验收的 Y4 2021–2024 预测、T030 同层参照及完整 V1 40 特征缓存。重核原数据与官方附件、原运行 / 模型 / 标签 / 目标映射 / 原生数组与缓存身份。S007/T033 不参与本轮股票模型拟合。

仅新增 Y4 的 2018→2019、2018–2019→2020 两次预热（800 轮）。Y4 与旧训练一致，以有效价格、有限原始标签为监督池，按日 1%/99% 缩尾、ddof=0 标准化、Huber alpha=0.9；训练顺序为股票 / 日期。每个预热剔除其各自最后训练交易日的跨界标签。预热本身也保存完整键预测、原生值、模型、目标映射和实际官方评分，作为真实训练记录。

第二阶段从 2019 起，外层 2021 / 2022 / 2023 只使用 2019–2020 / 2019–2021 / 2019–2022 的时间外预测；唯一 2024 候选只用 2019–2023 OOF。每折重新剔除外层最后交易日跨界标签；旧 OOF 最后一天可作为当年预测，但其跨入外层验证期的 y 不得作为当前第二阶段训练标签。

## 五臂与完整信号

- B10 / B20：全允许监督行，预测全市场真实收益 Top10% / Top20% 事件。
- R20 / R30：当天已知有效价格、非涨停股票中的 Y4 Top20% / Top30% 候选，预测**全允许监督池**真实 Top10% 事件。
- L30：同一 Top30% 候选，收益百分位按 0.60 / 0.80 / 0.90 / 0.95 变成 0–4；线性 gain、连续交易日 group、固定截断 466。

所有真实标签在有效价格、非涨停、有限 y 的监督池先定义，再筛候选；平均排名使相同收益不被分成不同真标签。候选只读取键、有效价格、涨停标志、Y4 原生分数，不接受 y 或缺 y 掩码；之后才去掉候选中无监督标签的行。精确候选边界并列按股票代码升序取固定人数。

全部第二阶段使用 40 个 V1 特征 + 全市场 Y4 日平均百分位（float32）；固定 T030 参数、seed=42、CPU 8 线程、400 轮，不加类别权重、不早停、不扩大网格。

B10/B20 的完整原生分数以缺价原始 0 兜底。R 系列用 `(候选标记, 第二阶段分数, 第一阶段分数)` 定义全市场完整排序；池外第二阶段项为 0，保持第一阶段相对次序；同第二阶段分数时用第一阶段，相同 tuple 仍保留精确并列。所有完整 raw 输出编码为日内**两倍平均排名**，再减去缺价原始零组的编码值，使该组仍为 0；这是保持全部严格次序和并列的单调平移，不是收益金额预测。原生模型分数及候选 mask 另存无损 `.npy`。

从已落盘 raw CSV 叠加一次原 q*，每年冷启动、全年连续；历史留仓不因掉出候选而额外清空。输出 / 原生编码 / q* 都做真实日期前缀核对，原生与 CSV 的完整排序 / ties 必须一致。候选召回、概率 AUC / logloss、事件精度均是辅助量，不替代官方收益与晋级规则。
