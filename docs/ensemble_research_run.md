## 排名与 CSV 保存

使用现有 `rank_blend` 的当日平均百分位，不直接混合不同目标尺度。保留该函数实际产生的浮点顺序与精确并列；为避免 CSV 解析合并近似值，融合后的保存编码为当日平均排名的两倍整数（1–9300）。这是严格保持实际顺序 / 并列组的单调编码，不能解释成收益率；原生浮点值另存无损 `native_rank_blend.parquet`。

单模型端点保留原 pred。旧 band 保留原实现；C018 / C042 直接使用 S004 已冻结代码和规则。每折控制器冷启动，所有输出 / 官方评分行序固定 `trade_date,ts_code`；处理层只接收键、pred、涨停标志和历史状态，不接收 y 或缺失 y 掩码。

评分以原始 y_ret_1d 为准；收益池删除涨停和缺 y，换手池只删除涨停。每个实际落盘文件从 CSV 重读后核对完整键、有限值、全排序 / 并列、实际 Top，并对照未修改官方评分器八指标（1e-10）。保存日 / 月 / 季、持仓段与换手诊断；月末不重置状态。真实派生记录注明新训练为 0。
