## 1. 为什么要重跑（LH001 的问题）

LH001 用「首日 top 组**冻结持有**整折的实现年化超额」作为判据，得到「2023 折
长周期模型明显更好（H01 +0.076 → H30 +0.178）」。但该判据有两个薄弱处：

1. 它衡量的是**一篮子股票在一段特定行情里的表现**，对单折的市场风格高度敏感
   （LH001 已看到 2024 折因 1 月风格崩塌而整体 ≈0）；
2. 它**不是排名质量**——一篮子拿对行情就能得分，与「模型能不能把真正的高收益
   股票排到前面」不是一回事。

因此本次按排名口径重做：**只看排名，不看收益率数值**。

## 2. 判据定义（排名重合度）

每个交易日 t：

1. 取投资域 = 官方换手候选口径：报价有效（`quote_valid`）且非涨停
   （`flag_limit_up == 0`），并要求**实际 h 日收益可算**（`close(t+h)` 存在；
   验证期末尾 h 个交易日因此自动排除）；
2. 组大小 $k=\lfloor N_t/10 \rfloor$，$N_t$ 为该日投资域股票数（实测 ≈434–443）；
3. 预测组 = 按**模型预测的 h 日收益**降序取前 $k$；
   实际组 = 按**实际** h 日收益降序取前 $k$；
4. **重合率** $= |预测组 \cap 实际组| / k$；同时报 Jaccard $= |\cap|/|\cup|$。

**随机基线 ≈ 0.100**：两个相互独立的 10% 集合的期望重合恰为 $k/N \approx 1/10$。
自检（400 只合成样本）：预测=实际 → 1.0000；预测=反序 → 0.0000；预测=随机 →
0.075。

> 注意：不同 h 的「实际组」噪声水平不同（h 越大，实际收益越可预测的持续性越强，
> 但个股方差也越大），所以跨 h 的重合率是「各模型在**自己那个预测问题**上识别
> 实际 top10% 的能力」，同尺度可比（随机基线都是 0.10），但不是同一个目标。

## 3. 协议

- **重新训练**：本折全部 5 个模型从零拟合（新产物目录 `LH002`，不复用 LH001
  的模型文件），共 10 个 LightGBM。参数与轮数仍**直读**
  `docs/optuna_tuning_S003_selection.json` 的 `winner.spec`（800 轮 / 28 叶 /
  lr 0.0407），不重调参。
- 折：fold1（训练 5,649,750 行 → 验证 2023）与 fold2（训练 6,775,050 行 →
  验证 2024），与 S003 的 wf2023 / confirm2024 同窗。
- 监督：`y_ret_{h}d = close(t+h)/close(t) − 1`，训练窗口末尾 h 个交易日的标签
  跨验证边界 → 置 NaN 剔除（h=1 剔 4,280 / 4,522 行）。
- 模型选择原则：看**两折**，不取只对单折好的 h。

## 4. 正确性校验

- h=1 重算标签与官方 `y_ret_1d` 逐位一致：7,895,700 行，NaN 模式差异 0，
  最大数值差 7.56e-16。
- H01（1 日基线）raw 指标逐位复现 S003：fold1 = 0.129125（wf2023 raw）、
  fold2 = 0.217000（confirm2024 raw）；与 LH001 的 H01 数值也完全一致 →
  本次「重新训练」在数值上等价于确定性复现，差异只来自判据。

## 6. 解读

1. **没有任何长周期模型在排名口径上击败 1 日模型。** H01 的两折均值和两折最差
   都是最高（0.11138 / 0.10696）；H20/H30 的两折均值反而低 0.4–0.5pp。
2. **2023 折的「优势」不成立，且正是过拟合的证据。** H20/H30 在 2023 只领先
   H01 **+0.27 / +0.21pp**（小于 1.5 个 SE，不显著），到 2024 就反转为
   **−1.17 / −1.08pp**（约 3.5–4 个 SE，显著为负）——折间符号相反，说明
   LH001 里 2023 的领先是**折特异性**，不是稳健的选股能力提升。这与「对 2023
   过拟合」的判断一致。
3. **所有模型都只在随机基线附近**（0.0953–0.1185 vs 0.100）。最好的组合
   （2023 折 H01）也只比随机高 1.58pp。即：给定当前特征与模型，对「实际
   top10%」的识别能力整体偏弱，这与 horizon IC 只有 0.02–0.10 是同一件事的
   两种表述。
4. **跨折反转（2023 重合率高于 2024，但 IC 更低）可解释**：2024 年 1 月崩盘
   使单日收益分布厚尾，实际 top10% 被模型不可预测的极端值主导，压低重合率
   （2024 折 H01 的 IC 0.0987 却只有 0.1070 重合，明显低于正态假设下
   ~0.134 的理论值）。排名 IC 度量中部，重合率度量尾部，二者不必同向。
5. **对生产接入的含义**：既然按排名口径长周期模型没有更好，就不应以「长周期
   选首日组」作为提分手段；LH001 里那些看起来漂亮的冻结组超额，是 2023 型
   行情放大的结果，不能外推。
