# LH033：band 段信号参数化 —— 部署点用在了这条曲线的最差端

> **状态说明（后置）**：本文推荐的配置 A / C 均已作废。C 在 Δfinal 上位居四折 argmax（+0.03627），
> 但其超额收益里 α（选股能力）只占 34%，远低于部署点 H01 路线的 76%；换长周期池内重排信号会把增益
> 从「选股能力」换成「层暴露」。**最终结论以 `docs/long_horizon_LH034_why_m8.md` 为准**，本文保留为阴性结果记录。

## 0. 起因：LH031 的「band 段不能动」是单折结论

LH031 断言「band 段不能动，改序 ⇒ ΔE 最大 −0.031」，据此把整条轴排除。
核对推导链时发现其依据 `experiments/LH031/free_ic_grid.csv` **只有 confirm2024 一折（25 行）**，
而文档写的是「30 变体 × 4 折实测」。补跑四折后结论反转。

本轮把该结论推广的那条轴完整扫开：**两段编码的第二参数（池内重排信号）就是一个普通的可调参数**，
它一直被固定在 `pct(H01)`，从未被扫描过。

```
two_stage(pr_mix, s_band, K):
    候选池 = pr_mix 分位 top K%
    池内   = 1 + norm(s_band | 池内)      ← s_band 就是 band 段信号，部署点恒为 pct(H01)
    池外   = pr_mix
```

自检（两项必须逐位通过）：
- `band=H01, φ=(0,0)` → IC 0.08630 / E 0.20828 / T 0.01838 / final 0.39149，与归档一致；
- `band=H01, φ=(−0.100,+0.040)` → Δfinal +0.02220 / ΔE +0.06940，即 M2，与 LH032 一致。

## 1. 四折结果：M2 不在帕累托前沿上

## 2. 机制验证：band 段信号存在最优 horizon，峰值不在 h=1

这是本轮最硬的一条——不是挑出来的点，是一条倒 U 曲线：

| horizon | F2T2 族，φ=(−0.125,+0.075) | F2T2 族，φ=(−0.040,+0.020) | F1T2 族，φ=(−0.125,+0.075) |
|---|---|---|---|
| h=1 (H01) | +0.02246 | — | — |
| h=5 | +0.03384 | +0.02856 (t 5.55) | +0.03505 |
| **h=10** | **+0.03656** | **+0.03201 (t 18.62)** | +0.03491 |
| h=20 | +0.03627 | +0.02794 (t 10.74) | +0.03212 |
| h=30 | +0.03313 | +0.02674 (t 6.34) | +0.02701（最小折 −0.00147） |

**部署点用的 h=1 是这条曲线上最差的一端。**

解释：候选池已由 `mix`（含 H01 权重 0.5）筛出，池内重排需要补充的是**更长周期**的信息，
所以最优 horizon 从全池排序的 h≈5 右移到 h≈10。这与记忆 §10 的「horizon 最优点 h≈5」不矛盾——
那条结论是**单模型全池**排序，本条是**池内重排**这一层的。

**为什么选 −0.040 而不是 −0.125**：后者的均值只高 0.0045，代价是折间 sd 大 3.4 倍、
微盘暴露从 0.446 涨到 0.549、持股天数少 9 天。在四折的分辨率下，+0.0045 不可分辨
（配对 t = 1.28，p = 0.29），而 sd 从 0.0034 到 0.0117 是实打实的稳健性损失。

注意 **H10_F2T2 无倾斜（φ=0）就已经 +0.01384 且四折全正**，微盘暴露只有 0.278 ——
band 段改动本身就是独立的一条增益，不与倾斜绑定。

## 5. 必须如实标注的代价

1. **微盘暴露仍然显著**：最小两档成交额的占比从部署点 18.5% 涨到 **44.6%**
   （M2 是 46.8%，推荐配置略低于 M2）。容量与冲击成本不被评分函数度量。
2. **超额主要来自 profile 而非 α**：ΔE +0.088 中 Δprofile(amt) +0.100、Δα 只有 +0.010。
   它比 M2 更依赖小成交额溢价（M2 的 Δα 是 +0.043）。
3. **vol60 层暴露反直觉**：虽然 φ_vol = +0.020（名义上往高波倾斜），名单落在最高两档波动的
   占比反而从 17.4% 降到 6.7%，最低两档从 17.2% 升到 33%。因为 log_amt 效应主导，
   而本数据集中极小成交额股恰是低波动股。φ_vol 的真实作用是**抵消一部分 amt 倾斜**，不是加高波暴露。
4. **配对 t 对 M2 不显著**（t = 1.28，p = 0.29，胜 3/4）。原因是 M2 在 2021 那一折特别强
   （+0.03253），而它在 2024 只有 +0.00149。四折分辨得了「新配置自身稳不稳」（t 18.62），
   分辨不了「它比 M2 好多少」。

## 6. 对既有结论的影响

- **M8（LH032 的推荐部署）被推翻**。M8 = H01 band 段 + 倾斜 + LH031 明线，Δfinal +0.02283；
  它建立在「band 段信号只能是 H01」这个从未被验证的假设上。
- **LH031 的明线轴（drop 段 rawmix，Δfinal +0.00084）在新框架下不再适用**：
  drop 段只存在于三段构造，而三段构造会削弱倾斜（top/rest 分段使位移跨不过段边界）。
  本轮的两段构造没有 drop 段。以 +0.032 对 +0.0008 的量级差，该轴可以放弃。
- 已推送的测试期文件 `dualtilt_test_run/test_pred_combo_rawmix.csv`（0.409252）需要按新配置重建。
