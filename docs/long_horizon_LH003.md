# LH003：长周期专属特征 × 截面 rank 目标（两折，统一 30 日评估口径）

- 分支：`model/long-horizon`（本地研究分支，**未并入 main**）
- 日期：2026-10-08；负责人：成员 B
- 代码：`src/long_horizon/features.py`（新增）、`run.py`（新增变体机制与
  `cross_sectional_rank` 目标）
- 配置：`configs/project.yaml` 的 `long_horizon.long_features` 与 `variants`
- 产物：`experiments/LH003_summary.csv`、
  `experiments/LH003_selection_quality_evalh5-10-20-30.csv`、
  `outputs/long_horizon/LH003/`
- **判据：统一评估周期（30 日）**。所有模型不论自身预测几日，其 top1/10 组一律按
  **实际 30 日收益**评估（定义见 `docs/long_horizon_LH002.md` 第 9 节），
  回答「谁更能选出长期有超额的股票」。

## 1. 为什么做这一轮

LH001/LH002 只把**标签的前瞻周期**从 1 日拉长到 30 日，特征（V1 的 40 个，最长
窗口 60 日）与目标形式（h 日累计收益）都没变，结论是长周期模型没有增量。本轮把
两个真正可能有用的东西换掉，做 2×2 对照：

| | V1 特征（40 个） | long 特征（59 个 = 40 + 19） |
|---|---|---|
| **raw 目标**（h 日累计收益） | `F1T1`（= LH001/LH002，已有） | `F2T1` ← 新 |
| **rank 目标**（当日截面百分位） | `F1T2` ← 新 | `F2T2` ← 新 |

- **长周期专属特征**（19 个，`lh_` 前缀，在 V1 之上叠加）：V1 窗口最长 60 日，
  对 5–30 日预测偏短，补 120/250 日量级 —— 长周期动量、跳月动量
  （`close(t−20)/close(t−250)−1`）、长均线偏置、长窗波动、长窗价格位置（距 250 日
  高低点）、长窗量能/额能比、上涨日占比、窗口内回撤、收益偏度，外加 2 个逐日截面
  排名（`rank_lh_ret_250`、`rank_lh_price_position_250`）。全部只向后看，
  `min_periods=w`，与 `src/features` 同一约定。
- **截面 rank 训练目标**：把监督标签换成**当日截面百分位排名**，对齐排名判据、
  屏蔽市场共同涨跌。

**其他一律不动**：参数与轮数直读 S003 `winner.spec`（800 轮 / 28 叶 / lr 0.0407），
折切分不变，边界规则不变（末个用到的交易日仍是 t+h−1，训练窗口末尾跨界的 h 日
标签置 NaN 剔除）。

## 2. 正确性校验

- h=1 重算标签与官方 `y_ret_1d` 逐位一致：7,895,700 行，NaN 模式差异 0，
  最大数值差 7.56e-16。
- 长特征输出自检：19 个特征、无全 NaN 列、覆盖率 77–97%；
  `long_feature_names` 带数量与去重断言。
- **H01 基线在两批实验里逐位相同**（hit_10 = 0.108489 / 0.105239，见下表），
  说明 LH003 与 LH002 的预测在同一口径下完全可比。

## 4. 结论

1. **长周期专属特征有效，而且是第一个跨两折稳定成立的改善。** `H20_F2T1` 的
   hit_10 两折 0.1255 / 0.1232（差仅 0.23pp），比 H01 的 0.1085 / 0.1052 高
   **+1.70 / +1.80pp**（约 6–8 个 SE），组 30 日超额从 +0.06%/+0.25% 升到
   **+0.57%/+2.10%（均值 +1.33%）**。对比 LH002 里"同类但没有长特征"的 H20
   （0.1193 / 0.0950）——**同样是 20 日预测周期，加上长特征后 2024 折从 0.0950
   跳到 0.1232**，把折间反转抹平了。这说明此前的「长周期无用」结论，问题不在
   预测周期，而在**特征窗口太短**。
2. **四个长特征变体（F2T1）全部两折一致优于 H01**，且 horizon 越接近 10–20 日
   越好（H20 最好）；20/30 日的折间差最小。
3. **rank 目标的作用与 raw 完全不同，不能只看 hit_10。** 长特征+rank（F2T2）
   在**平均实际百分位**和**掉队率**上最好（2024 折 H20_F2T2：0.5532 / 0.4238，
   即预测组平均落在实际前 44.7% 分位、只有 42.4% 掉进后 50%），但**严格命中率
   hit_10 折间不稳**（0.0981 → 0.1251）。若目标是「别让选进去的股票掉队」，
   rank 目标是对的；若目标是「命中 top10%」，raw 目标更稳。
4. **V1+rank（F1T2）是最差组合**：没有长特征支撑时，rank 目标反而把 hit_10
   压到 0.0819–0.0965（低于 H01）。**长特征是必要条件，rank 目标只是可选增强。**
5. **距离理论上界仍很远**：最好的组合在 2024 折拿到组 30 日超额 +2.29%，而上界是
   +31.12%；所有模型的 hit_10 仍在 0.083–0.126 区间（随机 0.100）。**方向对了，
   幅度还差一个数量级。**

## 5. 边界与诚实声明

- 两折均在 S003 中参与过调参，不是干净留出集；本轮 horizon / 折 / 参数全部预固定，
  **只有特征与目标形式是新引入的自由度**（长特征的窗口取值是先定的，未做搜索）。
- 测试期（2025–2026）本实验未触碰。
- `hit_10` 是逐日指标，日间不独立（30 日窗口高度重叠），SE 仅供量级参考。
- `avgret`/`rank` 类的窗口标签与本轮结论无关，属 LH004 的范围。
- 生产接入路径（本实验未执行）：首日 pred 替换成长周期预测、其余交易日 pred 不变，
  由留仓带维持首日集合 —— 现有 `band_scores` 零改动即可支持。但**是否接入需要先看
  LH004 的结果与三折一致性**。
