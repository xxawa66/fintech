# 数据字典

以下定义、行数与日期范围来自官方赛题 PDF；行数和缺失率尚未通过完整数据审计复核。

| 字段 | 含义 |
| --- | --- |
| ts_code | 股票代码，字符串，保留交易所后缀 |
| trade_date | 交易日期，YYYYMMDD 格式的整数 |
| open / high / low / close | 后复权开盘价、最高价、最低价、收盘价 |
| vol | 成交量，单位股 |
| amount | 成交额，单位元 |
| flag_limit_up | 当日是否涨停，1 为涨停，0 为未涨停 |
| flag_limit_down | 当日是否跌停，1 为跌停，0 为未跌停 |
| y_ret_1d | 未来一天收益率，close(t+1) / close(t) - 1，仅训练集提供 |

| 数据 | 官方行数 | 官方股票数 | 官方日期范围 |
| --- | ---: | ---: | --- |
| 训练集.csv | 7,900,350 | 4650 | 20180102—20241231 |
| 测试集_X.csv | 1,599,600 | 4650 | 20250102—20260608 |

训练标签约 14.5% 缺失。后续审计需核对停牌、未上市等情况，并记录处理方式。特征计算不能使用未来价格或未来标签。

数据文件的实际字节大小及 SHA-256 见 `data/manifest.json`。官方测试标签不在当前附件中。
